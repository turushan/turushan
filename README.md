## 🌐 Website checks

- 🕳️ [**Indie404**](https://indie404.com) checks whether a site returns a real missing-page response instead of a soft 404, redirect, or server error.
- ♿ [**IndieA11y**](https://indiea11y.com) checks one page's Lighthouse accessibility score and explains every failed audit in plain English.
- 💔 [**IndieBrokenLinks**](https://indiebrokenlinks.com) checks up to 200 links on one page and puts broken destinations first.
- 🧭 [**IndieCanonical**](https://indiecanonical.com) checks canonical and hreflang links for conflicts, chains, and missing return links.
- 🕷️ [**IndieCrawl**](https://indiecrawl.com) checks whether search engines and AI bots can crawl a website.
- 🛡️ [**IndieHeaders**](https://indieheaders.com) checks a site's security headers and gives the line to add for every gap.
- 🤖 [**IndieLLMs**](https://indiellms.com) validates a site's `llms.txt` file for people publishing documentation for AI systems.
- 🏝️ [**IndieOrphans**](https://indieorphans.com) finds sitemap pages that no other checked page links to, across up to 200 pages.
- ↪️ [**IndieRedirect**](https://indieredirect.com) traces every HTTP redirect hop, its status code, and the final URL.
- 🧱 [**IndieSchema**](https://indieschema.com) inspects JSON-LD and checks common Google search feature requirements.
- 📮 [**IndieSecurityTXT**](https://indiesecuritytxt.com) checks a site's `security.txt` against RFC 9116 and explains every gap.
- 🗺️ [**IndieSitemap**](https://indiesitemap.com) checks sitemap discovery, structure, URLs, dates, and sampled page responses.
- ⚡ [**IndieSpeed**](https://indiespeed.com) checks mobile and desktop performance, Core Web Vitals, and the three fixes worth doing first.
- 🌍 [**IndieWWW**](https://indiewww.com) checks whether apex and `www` hosts resolve and redirect to one canonical home.

## 🧰 Builder utilities

- ⏰ [**IndieCrontab**](https://indiecrontab.com) explains a cron expression, shows its next runs, and checks whether major platforms accept it.
- 📷 [**IndieEXIF**](https://indieexif.com) reads photo metadata locally and downloads a clean copy without changing the encoded picture.
- 🧩 [**IndieJSON**](https://indiejson.com) lets you inspect, edit, and repair JSON locally without sending it anywhere.
- 🔐 [**IndieJWT**](https://indiejwt.com) decodes JWTs, explains expiry, and verifies signatures locally with a public key or JWKS URL.
- 📜 [**IndieOpenAPI**](https://indieopenapi.com) validates OpenAPI documents for structural errors, broken references, incomplete operations, and authentication gaps.
- 📱 [**IndieQR**](https://indieqr.com) turns text or a URL into downloadable QR code images without a tracking redirect.
